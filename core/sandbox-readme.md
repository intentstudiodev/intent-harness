# Sandbox

Working memory, not knowledge. Nothing here is true about the product until it is in the KB (`V*/`) through a checkpoint. Files are appended to, never rewritten (two exceptions: `where-we-stopped.md`, three lines about where work stopped, rewritten at the end of every use case; and `pipelines.md`, the spec tools connected to this project and the features handed to them, two tables updated in place by `build/connect-pipeline.md`, `build/hand-to-pipeline.md` and `build/follow-pipeline.md`); what is finished moves to `archive/`, nothing is deleted. What the user hands over is not here: it lives in `../inputs/`, where cards can cite it. Questions for the owner are not here either: they live in the cards (`[ask: …]`) and `intent-format open` lists them.

Feature packs for spec tools are in `packs/` (`build/hand-to-pipeline.md`).
