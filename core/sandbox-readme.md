# Sandbox

Working memory, not knowledge. Nothing here is true about the product until it is in the KB (`V*/`) through a checkpoint. Files are appended to, never rewritten; what is finished moves to `archive/`, nothing is deleted. What the user hands over is not here: it lives in `../inputs/`, where cards can cite it. Questions for the owner are not here either: they live in the cards (`[ask: …]`) and `intent-format open` lists them.
