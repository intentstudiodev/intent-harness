# starters

1. Find the matching file in `starters/domains/` or `starters/areas/`. None → say so; do not invent a starter.
2. Show the items in the file's order, each with its mark (`usually` · `sometimes` · `avoid`) and its why. Ask: keep, drop, or change, per item or "all usually".
3. Kept items go to checkpoint as facts the user confirmed (unmarked; the starter file is the suggestion, the user is the source); dropped ones are noted in the research file so they are not offered again.
4. Nothing enters the KB without the checkpoint. Starters are suggestions, never defaults.
