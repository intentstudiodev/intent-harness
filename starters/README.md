# Starters

Typical shapes for common kinds of product (`domains/`) and common areas (`areas/`). Suggestions the user keeps or drops item by item; never defaults; nothing enters the KB without a checkpoint.

One shape per file:

```
# <domain or area>
## user types      - <item> · usually|sometimes|avoid · why
## journeys        …
## screens         …
## rules           …
## edge cases      …
## integrations    …
## ask early       - <question worth asking before building>
## common mistakes - <mistake> · why it hurts
## practice        - <design or development practice note> · why
```

Sources must be named at the top of each file. The library is thin at 1.0; a proper survey is pending (see the maintainer's notes).
