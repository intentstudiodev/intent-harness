# No messages before a booking request · #DC000002
> ⚙ #DC000002SGV1.0 · V1.0 in-progress

## Question
Can a User message an Owner about a listing before sending a booking request?

## Why
Owners' time is the scarce resource; a request with a payment hold is a strong enough signal to earn a conversation. [assumed]

## Options
1. Open enquiries from the listing — more questions answered, but inboxes fill with people who never book and owners move deals off-platform.
2. Messages only once a request exists (chosen) — every conversation has a booking context; some users want to ask first and will not.
3. A fixed question form before booking — structured, but still unpaid work for owners.

## Outcome
Messages exist only for a booking request or trip; the listing answers the common questions through house rules and amenities.
