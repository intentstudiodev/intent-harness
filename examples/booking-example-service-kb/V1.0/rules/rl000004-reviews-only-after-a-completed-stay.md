# Reviews only after a completed stay · #RL000004
> ⚙ #RL000004SGV1.0 · V1.0 in-progress

## Description
**R1 · EARS** If a booking's check-out has passed and 14 days have not, then the system shall allow the User one review of that stay; otherwise it shall not.

## Why
Reviews tied to real stays and written while the memory is fresh are the only ones worth reading. [assumed]
