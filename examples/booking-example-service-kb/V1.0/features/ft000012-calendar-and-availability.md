# Calendar and availability · #FT000012
> ⚙ #FT000012SGV1.0 · V1.0 in-progress

## Description
Lets an Owner see bookings on a calendar and block or open dates.
**R1 · User story** As an Owner, I want to block dates I keep for myself, so that nobody can request them.

## Why
Blocked dates are the owner's main lever against unwanted requests, and the only way to avoid double bookings with stays sold elsewhere. [assumed]
