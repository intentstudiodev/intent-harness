# Requests and bookings · #FT000013
> ⚙ #FT000013SGV1.0 · V1.0 in-progress

## Description
Lets an Owner review incoming booking requests, accept or decline them, and see confirmed and past bookings.
**R1 · User story** As an Owner, I want to see who is asking, for which dates and how much I earn, so that I can decide quickly.

## Why
Owners approve requests by default (see the instant-book decision), so the request queue is their daily work.
