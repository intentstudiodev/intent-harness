# Manage listings · #FT000011
> ⚙ #FT000011SGV1.0 · V1.0 in-progress

## Description
Lets an Owner create, edit, publish and unpublish listings: description, photos, price and house rules.
**R1 · User story** As an Owner, I want to edit my listing's photos and price any time, so that it stays accurate.

## Why
The listing is the owner's product page; it has to be editable without help. [assumed]
