# Messages · #FT000009
> ⚙ #FT000009SGV1.0 · V1.0 in-progress

## Description
Lets a User and an Owner talk about a specific booking request or trip inside the product.
**R1 · User story** As a User, I want to message the owner about my booking, so that check-in details are settled before I arrive.

## Why
Arrival details and small questions otherwise move to phone and email, where the platform can't help when something goes wrong. [assumed]
