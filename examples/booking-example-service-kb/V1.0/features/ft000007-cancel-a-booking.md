# Cancel a booking · #FT000007
> ⚙ #FT000007SGV1.0 · V1.0 in-progress

## Description
Lets a User cancel an upcoming trip and see exactly what is refunded.
**R1 · User story** As a User, I want to know my refund before I confirm a cancellation, so that I can decide with full information.

## Why
Plans change; a clear refund up front is cheaper than disputes afterwards.
