# Payouts · #FT000014
> ⚙ #FT000014SGV1.0 · V1.0 in-progress

## Description
Lets an Owner see upcoming and past payouts and where the money goes.
**R1 · User story** As an Owner, I want to see when each payout is released, so that I can plan my cash.

## Why
Owners judge the platform by whether the money arrives when promised; showing the schedule removes most questions. [assumed]
