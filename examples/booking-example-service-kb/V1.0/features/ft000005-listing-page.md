# Listing page · #FT000005
> ⚙ #FT000005SGV1.0 · V1.0 in-progress

## Description
Lets a Guest or User read everything about one place and start a booking from it.
**R1 · User story** As a Guest, I want to read a listing with photos, price, house rules and reviews, so that I can decide without asking.

## Why
The listing is where the decision is made; photos, price and reviews must sit together.
