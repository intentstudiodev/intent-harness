# Become an owner · #FT000010
> ⚙ #FT000010SGV1.0 · V1.0 in-progress

## Description
Lets a User register as an Owner, including the identity check.
**R1 · User story** As a User, I want to become an owner in a few steps, so that I can list my place this week.

## Why
Owners handle other people's homes and money; the platform needs to know who they are before anything goes live.
