# Reviews · #FT000008
> ⚙ #FT000008SGV1.0 · V1.0 in-progress

## Description
Lets a User rate and describe a completed stay, and shows those reviews on the listing.
**R1 · User story** As a User, I want to review a place I stayed at, so that the next guest knows what to expect.

## Why
Reviews are the trust signal guests read most; they must come from real, completed stays.
