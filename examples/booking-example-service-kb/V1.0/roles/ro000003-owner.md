# Owner · #RO000003
> ⚙ #RO000003SIV1.0 · V1.0 in-progress

## Description
A User who registered as an owner and passed the identity check: creates and edits listings, keeps the calendar current, answers booking requests, and watches bookings and payouts. Usually has one or two places and checks in daily on the phone while a request is open.

## Why
An owner is a User with extra duties, not a separate account, so one person can both travel and host.
