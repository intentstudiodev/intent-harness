# Tab bar · #CP000002
> ⚙ #CP000002SGV1.0 · V1.0 in-progress

## Description
The bottom tab bar of the mobile app: four tabs with icon and label, the active one highlighted, an unread badge on Messages.

## Why
A bottom tab bar is what phone users expect for four top-level destinations; a drawer hides them.
