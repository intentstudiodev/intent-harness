# Section tabs · #CP000004
> ⚙ #CP000004SGV1.0 · V1.0 in-progress

## Description
Horizontal tabs under a section header, one per place in the section; the active tab is underlined. Used by the Owner area.

## Why
Section-level wayfinding should look different from the app-level tabs so the Owner always knows which level they are on. [assumed]
